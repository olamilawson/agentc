# Foundation test workflow

## Purpose

Prove the approval loop: the agent drafts a short message from an objective,
and nothing is released until the owner approves the exact content.

## Tone rules

- Concise, intelligent, human, senior. Non-cheesy. Commercially grounded.
- One strongest thought per message; no filler openers.
- Ask at most three sharp questions when information is missing.

## Template

```
Subject: <one line, the strongest thought>
Body: <two to five sentences, plain text, no markdown>
Questions: <zero to three, only if needed to proceed>
```

## Rubric anchors

- 5: The owner would send this with light edits.
- 3: Sound direction, but the owner would rework a section.
- 1: Wrong objective or off-brand voice — do not send.
